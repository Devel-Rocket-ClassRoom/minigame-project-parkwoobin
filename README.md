# 골목고양이 생존기 (Stray Cat Adventure)

사람이었던 주인공이 의문의 사건으로 고양이가 되어, **사람의 기억을 가진 채 골목에서 살아남는** 2D 도트 횡스크롤 생존 액션 게임입니다.

## 게임 소개

- **장르**: 2D 도트 횡스크롤 생존 액션
- **엔진**: Unity 6 (6000.3.15f1) / URP
- **조작**: 모바일 가상 조이스틱 + 액션 버튼 (PC 키보드 테스트 입력 지원)

### 플레이 흐름

```
프롤로그 → 튜토리얼 맵 → Map1 → Map2 → Map3(도시) → Map4(하수구) → Map5(병원) → 엔딩
```

- 좌우로 이동하며 먹이·코인을 모으고, 사람·개·고양이·거미 등 위험 요소를 회피하거나 제압합니다.
- **배고픔**이 시간에 따라 감소하고, 0이 되면 체력이 지속적으로 깎입니다.
- 구역마다 배치된 **깃발(SaveSpot)** 에 닿으면 체크포인트가 저장되고, 게임 오버 시 마지막 깃발에서 재시작합니다.
- 각 맵에는 진행 방향을 알려주는 **경로 안내 화살표**가 표시됩니다.

### 주요 기능

| 기능 | 설명 |
|---|---|
| 성장 시스템 | 코인으로 이동속도 · 대시 속도/쿨타임 · 점프력 · 턴 쿨타임 · 최대 체력 · 식사 효율 강화 |
| 스킬 해금 | 진행도에 따라 대시 · 공격 · 턴 등 스킬 순차 해금 |
| 세이브 슬롯 | 슬롯 단위 저장/불러오기, 체크포인트 자동 저장 |
| 온라인 랭킹 | Firebase 기반 로그인 · 프로필 · 리더보드 |
| 다국어 | 한국어 / 영어 실시간 전환 |
| 튜토리얼 | 팝업 트리거 기반 인게임 조작 안내 및 팁 패널 |

## 게임 디자인 요약

아래 내용은 [`GDD.md`](GDD.md)의 초기 MVP 기획을 요약한 것입니다. 현재 출시 빌드의 맵 구성, 조작 방식 및 세부 수치는 개발 과정에서 달라질 수 있습니다.

### 세계관과 목표

주인공은 의문의 사건으로 정신을 잃은 뒤 낡은 상자 안에서 고양이로 깨어납니다. 사람의 기억이 남아 있어 돈의 가치와 가게 구조, 사람의 행동을 이해하며, 골목에서 생존하는 동시에 자신이 고양이가 된 이유를 추적합니다.

| 구분 | 목표 |
|---|---|
| 단기 목표 | 먹이와 돈을 모으고 사건과 위험을 극복해 스테이지를 진행 |
| 승리 조건 | 경험치 게이지 100% 달성 후 클리어 지점 도착 |
| 패배 조건 | 체력이 0이 되거나, 배고픔 고갈 후 지속 피해로 체력 소진 |
| 장기 목표 | 높은 점수, 신규 맵과 능력 해금, 변신 원인에 관한 단서 수집 |

### 기본 플레이 루프

```text
스테이지 시작
→ 골목 탐색
→ 먹이·돈·경험치 수집
→ 사람·동물·장애물 사건 발생
→ 도망·숨기·상호작용·전투 선택
→ 피버 게이지 충전 및 발동
→ 경험치 100% 달성
→ 클리어 연출·점수 정산·자동 저장
→ 다음 스테이지
```

### 주요 자원과 아이템

| 자원 | 역할 |
|---|---|
| 체력 | 적의 공격과 위험 요소에 피격되면 감소하며, 0이면 게임 오버 |
| 배고픔 | 시간에 따라 감소하고, 고갈되면 체력이 지속적으로 감소 |
| 돈 | 능력 강화와 아이템 구매에 사용 |
| 경험치 | 사건 해결과 수집 행동으로 획득하며, 100%가 되면 스테이지 클리어 |

먹이는 생선, 참치캔, 우유, 닭다리, 썩은 음식으로 구성됩니다. 각 음식은 배고픔 또는 체력을 회복하고 서로 다른 점수를 제공합니다. 동전, 지폐, 지갑, 배달 봉투는 성장 재화나 랜덤 보상을 제공합니다.

### 피버타임

피버 게이지가 가득 차면 사람의 판단력과 고양이의 본능이 결합된 강화 상태를 발동할 수 있습니다.

- 이동속도와 점수 배율 증가
- 돈 획득량 증가
- 사람의 감지 범위 감소
- 사람이나 다른 고양이의 물건과 먹이 획득 가능
- 짧은 무적 시간 제공

### 적과 사건

| 분류 | 종류 | 주요 행동 |
|---|---|---|
| 사람 | 일반인, 아이, 가게 주인, 경비원 | 감지 후 추격, 불규칙 이동, 먹이 감시 |
| 우호 NPC | 착한 사람 | 접근한 고양이에게 먹이 제공 |
| 동물 | 경쟁 고양이, 보스 고양이, 개, 거미 | 먹이 경쟁, 공격, 빠른 추격 |
| 장애물 | 자동차, 오토바이, 자전거, 높은 벽, 좁은 통로 | 충돌 위험 또는 점프·숨기·타이밍 이동 요구 |

대표 사건으로는 사람의 추격, 쓰레기통 탐색, 생선 상자 훔치기, 다른 고양이와의 대치, 개 추격, 높은 장애물과 좁은 통로 통과, 휴식 장소 회복이 있습니다.

### 스테이지 기획

| 단계 | 배경 | 핵심 학습과 도전 |
|---|---|---|
| Stage 1 | 시골 골목 | 이동, 점프, 먹이 획득, 사람 회피 |
| Stage 2 | 작은 마을 | 숨기, 쓰레기통 상호작용, 감지 범위 회피 |
| Stage 3 | 시장 골목 | 생선 훔치기, 빠른 추격과 경쟁 고양이 대응 |
| Stage 4 | 아파트 단지 | 은신, 경비원 감시, 자전거 장애물 회피 |
| Stage 5 | 번화가 골목 | 개와 차량 등 복합 위험, 피버타임 활용 |
| Stage 6 | 밤거리 | 제한된 시야에서 보스 구역 돌파 |

### 점수와 성장

점수는 먹이와 돈 획득, 사람 회피, 전투 승리, 사건 해결, 피버타임 발동, 스테이지 클리어 결과를 합산합니다. 획득한 돈으로 다음 능력을 강화하는 구조입니다.

- 이동속도 증가
- 최대 체력 증가
- 배고픔 감소 속도 완화
- 공격 능력 강화
- 피버 보상과 지속시간 증가

### UI와 아트 방향

인게임 HUD는 체력, 배고픔, 경험치, 점수, 돈, 위험 경고와 모바일 조작 버튼을 표시합니다. 결과 화면에서는 최종 점수, 획득 재화, 수집 및 사건 통계를 제공합니다. 아트는 32×32 기반의 귀여운 2D 도트 스타일이며, 진행할수록 골목의 분위기와 위험도가 복잡해지는 방향을 지향합니다.

### 에디터 테스트 조작

| 입력 | 동작 |
|---|---|
| `←` / `→` | 좌우 이동 |
| `↓` | 숨기기 / 낮은 자세 |
| `Space` | 점프 |
| `A` | 공격 |
| `S` | 턴 |
| `D` | 대시 |

### 실행 방법

1. 저장소를 내려받습니다.
2. Unity Hub에서 프로젝트 폴더를 **Unity 6000.3.15f1**로 엽니다.
3. Package Manager가 `Packages/manifest.json`의 패키지를 복원하고 스크립트 컴파일을 마칠 때까지 기다립니다.
4. `Assets/Scenes/Main.unity`를 열고 Play 버튼을 누릅니다.

Android 빌드는 `File > Build Profiles`에서 Android 플랫폼을 선택한 뒤 진행합니다. 빌드에 포함되는 씬은 `Main → Prologue → TutorialMap → Map1~Map5 → Ending` 순서로 설정되어 있습니다.

> Firebase 연동에는 `Assets/google-services.json` 이 필요합니다. 저장소에 포함되어 있지 않은 경우 Firebase 콘솔에서 내려받아 배치하세요.

> `KeyboardTestInput`은 에디터 테스트용 컴포넌트입니다. 배포 빌드에서는 비활성화하거나 제거하세요.
